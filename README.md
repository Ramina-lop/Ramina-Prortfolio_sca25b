# Ramina-Prortfolio_sca25b

Personal Portfolio — Ramina Zununova

Персональный сайт-портфолио, созданный с использованием HTML, CSS и JavaScript. Сайт содержит информацию об образовании, навыках, проектах, опыте и контактных данных.

🚀 Запуск проекта

1. Скачайте ZIP-архив проекта.
2. Распакуйте его в удобную папку.
3. Откройте папку проекта в Visual Studio Code.
4. Откройте файл index.html.
5. Запустите сайт через расширение Live Server (нажмите правой кнопкой мыши на index.html → Open with Live Server).

Также сайт можно открыть напрямую через браузер, открыв файл index.html.







🛠 Используемые технологии

* HTML5 — структура и содержание сайта.
* CSS3 — оформление, адаптивность, анимации и стилизация элементов.
* JavaScript — интерактивные функции сайта.






⚙️ Реализованные JavaScript-функции

1. Мобильное меню — открытие и закрытие навигационного меню на мобильных устройствах.
2. Фильтрация проектов — отображение проектов по выбранным категориям.
3. Модальное окно проекта — просмотр дополнительной информации о выбранном проекте.
4. Валидация контактной формы — проверка введённых данных и отображение сообщений об ошибках или успешной отправке.
5. Back to Top — плавающая кнопка, которая появляется при прокрутке страницы вниз и позволяет плавно вернуться в начало сайта.
